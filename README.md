# Personal Codex skills

Personal Codex skills maintained by `web2bear`. This repository stores the skill definitions and their supporting files. Some skills contain paths and conventions specific to the author's Windows environment; review those before installing elsewhere.

| Skill | Purpose |
| --- | --- |
| `clean-slice-review` | Review Clean Architecture and Vertical Slice boundaries. |
| `premium-infographic` | Generate Russian educational PNG infographics. |
| `windows-software-finder` | Research and compare Windows software. |
| `obsidian-interview-article` | Create interview preparation notes in Obsidian. |
| `rapid-skill-learning` | Run practice-first learning sessions. |

Each directory under `skills/` is a separate skill. Copy the desired directory to a user skill location such as `%USERPROFILE%\.agents\skills\` or `%USERPROFILE%\.codex\skills\`, then refresh skill discovery in Codex.
