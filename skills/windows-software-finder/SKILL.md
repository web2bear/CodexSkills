# Поиск программ для Windows 11

Находи и сравнивай программы по описанию функций или как альтернативы известному продукту. При выборе учитывай соответствие задаче, подтвержденную поддержку Windows 11, бесплатность и темп разработки. Источники и их ограничения находятся в [SOURCES.md](SOURCES.md).

## Порядок поиска

1. Выдели обязательные функции и ограничения из запроса. Ищи на русском и английском, используя синонимы функций. Если важная для выбора характеристика неизвестна (например, коммерческое использование или ARM64), задай один короткий уточняющий вопрос; иначе продолжай с явными допущениями.
2. Найди кандидатов через веб-поиск, подходящие каталоги из `SOURCES.md` и, для open source/community-проектов, поиском репозиториев GitHub. Для GitHub используй ключевые слова и синонимы; при необходимости `in:readme`, `topic:`, `language:`, `pushed:` и `archived:false`. GitHub — дополнительный канал, не единственный.
3. Проверь каждого кандидата по официальному сайту продукта, документации, тарифам, системным требованиям и официальному источнику загрузки. Каталоги, репозитории поиска и обзоры помогают обнаружить или сравнить кандидатов, но не заменяют первичные источники.
4. Точно укажи модель распространения: freeware, бесплатный тариф с ограничениями, пробная версия или платная программа. Отдельно помечай open source. Проверь ограничения для личного/коммерческого использования, если они влияют на запрос.
5. Оцени активность по дате последнего стабильного релиза. Если релизы редкие или страница релизов отсутствует, проверь датированные изменения в официальном репозитории, журнале изменений или новостях проекта и оцени темп в контексте. Покажи даты и ссылки; не используй единый срок отсечения.
6. Ищи на YouTube свежие обзоры по названию программы и её актуальной версии. Добавляй до двух подходящих роликов на программу, если они существуют; указывай название, канал и дату публикации. Используй видео как пользовательский опыт, не как подтверждение цены, системных требований или фактических характеристик. Если подходящих свежих обзоров нет, не подменяй их старыми роликами.
7. Ранжируй сначала по совпадению с функциями и подтвержденной поддержке Windows 11, затем по бесплатности и признакам активной разработки. Если подходящих кандидатов меньше пяти, не добавляй слабые варианты только ради количества.

## Формат ответа

Дай 3–5 коротких карточек, если столько подходящих вариантов найдено. В каждой карточке укажи:

- **Почему подходит:** совпадающие функции и важные отличия.
- **Цена:** freeware, ограничения бесплатного тарифа или пробный период; отдельно — open source, если подтверждено.
- **Windows 11:** подтвержденная поддержка и ссылка на требования; если официального подтверждения нет, скажи об этом.
- **Свежесть:** дата последнего стабильного релиза или другого датированного изменения и краткий контекст темпа.
- **Ссылки:** официальный сайт и официальная загрузка.
- **Видео:** до двух свежих релевантных YouTube-обзоров с датами, если доступны.

Ставь ссылки рядом с подтверждаемыми сведениями. Явно отмечай неопределенность. Не называй программу бесплатной, совместимой или активно развиваемой только по карточке каталога, наличию в пакетном менеджере, числу звезд или дате ролика.
