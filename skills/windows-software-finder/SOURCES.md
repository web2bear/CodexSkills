# Источники поиска программ для Windows 11

Этот перечень можно редактировать независимо от рабочего процесса в `SKILL.md`. Источники ниже помогают находить кандидатов. Перед рекомендацией проверяй функции, цену, поддержку Windows 11 и загрузку у разработчика.

## Веб-поиск и первичные источники

- **Веб-поиск** — ищи по запросу и синонимам на русском и английском; делай отдельные запросы для функций, модели оплаты, официальной страницы/релизов и свежих обзоров.
- **Официальный сайт разработчика** — главный источник описания, цены, требований и официальной загрузки.
- **Официальные релизы, changelog и репозиторий** — первичный источник для дат релизов и других изменений.

## Каталоги и справочники

- **AlternativeTo** — <https://alternativeto.net/browse/>  
  Каталог альтернатив с фильтрами платформы и лицензии. Используй для обнаружения кандидатов; карточки и пользовательское ранжирование перепроверяй у разработчика.
- **WinGet** — <https://learn.microsoft.com/en-us/windows/package-manager/winget/search>  
  Ищи пакет, ID и имя приложения. Наличие записи подтверждает лишь наличие пакета в источнике, а не бесплатность, качество или активную разработку.
- **Remontka.pro** — <https://remontka.pro/category/soft/>  
  Русскоязычные инструкции, обзоры и подборки программ. Хорош для поиска практических сценариев и названий; цену и загрузку подтверждай у разработчика.
- **MajorGeeks** — <https://www.majorgeeks.com/>  
  Каталог Windows-утилит и freeware, включая нишевые программы. Используй для discovery; официальный сайт остаётся предпочтительной страницей загрузки.
- **FossHub** — <https://www.fosshub.com/>  
  Каталог freeware и open source с описаниями проектов и страницами версий. Проверяй лицензию и переходи к официальной странице проекта; сама запись не гарантирует безопасность файла.
- **PortableApps.com** — <https://portableapps.com/apps>  
  Каталог портативных приложений для Windows. Учитывай, что он охватывает только portable-варианты и может включать упаковки стороннего проекта.

## GitHub

- **Поиск репозиториев** — <https://github.com/search?q=in%3Areadme+windows+utility&type=repositories>  
  Ищи названия функций и их синонимы; уточняй `in:readme`, `topic:`, `language:`, `pushed:` и `archived:false`. Документация синтаксиса: <https://docs.github.com/en/search-github/searching-on-github/searching-for-repositories>. Проверяй README, лицензию, релизы и идентичность официального репозитория. GitHub полезен для open source/community-программ, но не покрывает большую часть закрытого ПО.

## YouTube

- **Поиск видео** — <https://www.youtube.com/results?search_query=Windows+software+review>  
  Ищи по названию приложения, ключевой функции, `review`, `Windows 11` и текущему году. Проверяй канал, дату, версию программы и содержание ролика. Не считай число просмотров доказательством качества; для результата бери прямую ссылку на ролик, а не страницу выдачи.
