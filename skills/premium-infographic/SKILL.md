# Premium Infographic

Создай содержательно точную, визуально выразительную образовательную инфографику. Итог: PNG, предпросмотр, путь к файлу и полный промпт последней генерации.

## Параметры и взаимодействие

По умолчанию: `style=dark-neon`, `mode=balanced`, `format=16:9`, `language=ru`. Явные параметры пользователя всегда имеют приоритет. Аудиторию и уровень детализации выводи из запроса; иначе объясняй понятным языком для заинтересованного новичка.

Если указана только тема, предложи один компактный интерактивный выбор. В доступном инструменте вопросов покажи три вопроса: стиль, режим и формат. Для формата нужны четыре варианта — используй инструмент, который их поддерживает; иначе предложи все варианты обычным сообщением. Кратко опиши варианты из [references/options.md](references/options.md). Дай явный способ выбрать всё по умолчанию одним ответом. Дождись ответа перед генерацией; не трактуй молчание как выбор.

Если пользователь пишет «по умолчанию», «без вопросов», `defaults` или уже задаёт параметры, не спрашивай о пропущенных настройках: дополни их значениями по умолчанию и работай. Спрашивай только если неоднозначность самой темы мешает корректному результату.

Примеры:
- `$premium-infographic Фотосинтез` — предложить параметры.
- `$premium-infographic Фотосинтез, по умолчанию` — сразу генерировать.
- `$premium-infographic Сборка мусора .NET, minimal-science, educational, 4:5` — применить параметры, подписи на русском.
- `$premium-infographic Нейрон, glass-dashboard, visual, 1:1, English` — английские подписи.

## Содержание и композиция

1. Определи центральную мысль, необходимые понятия и отношения. Проверь нестабильные, спорные или узкоспециальные факты по первичным источникам, если доступны инструменты поиска. Не выдумывай статистику, цитаты и источники. Без проверки не включай сомнительные численные утверждения. Источники укажи рядом с результатом, не засоряя мелким текстом изображение.
2. Выбери визуальную грамматику по смыслу: процесс → последовательность; система → слои или связи; сравнение → параллельные колонки с общими критериями; устройство → разрез; причины → направленный граф; количественные данные → график только по реальным данным. Метафора должна объяснять тему; явно отличай условную метафору от буквальной научной структуры.
3. Прочитай только выбранный стиль из `references/styles/`: [dark-neon](references/styles/dark-neon.md), [minimal-science](references/styles/minimal-science.md), [glass-dashboard](references/styles/glass-dashboard.md). Применяй режим и формат из [references/options.md](references/options.md). Используй одну доминирующую композицию, ясную иерархию и читаемые подписи. Сокращай содержание, если оно не помещается; не уменьши шрифт до нечитаемого.
4. Подготовь точные подписи на языке пользователя, русском по умолчанию. Утверди их внутренне до генерации, проверь смысл стрелок, причинность и терминологию. Составь полный промпт по [references/prompt-template.md](references/prompt-template.md).

## Генерация: только встроенный imagegen

Применяй установленный `$imagegen` и его встроенный режим. Проверь наличие навыка и доступного callable инструмента `image_gen` / `image_gen.imagegen` (в некоторых окружениях имя `image_gen__imagegen`). Наличие файла навыка само по себе не доказывает доступность генератора.

Если генератор отсутствует или вызов завершается ошибкой, сообщи конкретное ограничение. Сохрани готовый промпт, если запись доступна. Не используй CLI image_gen.py, внешние API, API-ключи, внешние сервисы или подмену изображением из HTML/SVG. Не утверждай, что изображение создано, пока инструмент не вернул результат.

### Получение результата встроенного генератора

Не предполагай, что ответ генератора всегда является массивом `content`. Вызов через `functions.exec` может вернуть объект вида `{ image_url: "data:image/png;base64,...", output_hint: "..." }` напрямую. Для такого ответа немедленно передай весь объект в `generatedImage(result)`, чтобы показать изображение пользователю; не выводи `image_url`, base64 или полный объект через `text()`/`JSON.stringify()`. Если ответ имеет вид MCP с `content`, передай блоки типа `image` через `image(block)`, а текстовые блоки используй только для метаданных. Учитывай обе формы результата.

Считай генерацию успешной, только если получен фактический image payload или подтверждённый файл. Если есть `output_hint`, извлеки из него возвращённый путь и проверь наличие файла, сигнатуру PNG и размеры; сам текст `output_hint` не является доказательством существования файла. Если получен image payload без пути, покажи его через `generatedImage` и сохрани его в рабочую папку только если среда предоставляет реальный файл или поддерживаемый способ записи. Не заявляй, что результат отсутствует только потому, что в ответе нет `content`.

При сетевой ошибке допустима одна повторная попытка без изменений входного промпта. Если и она завершилась сетевой ошибкой, прекрати повторы и сообщи о сбое. Не сокращай содержательный промпт автоматически как предполагаемое исправление сетевой ошибки: сначала различи сетевую ошибку и успешный ответ, который был неправильно разобран.

Референсы необязательны: пользователь может приложить изображения или указать локальные файлы. Дополнительные постоянные референсы можно положить в `assets/references/`. Правила ролей и подключения: [references/reference-images.md](references/reference-images.md). Не загружай всю библиотеку автоматически.

Укажи желаемое соотношение сторон в промпте; не придумывай отсутствующие параметры размера инструмента. Используй только его фактическую схему. После генерации проверь реальные размеры и соотношение сторон: допустимое отклонение 1%. Если формат не соблюдён, сначала запроси одну целевую перегенерацию. Если проблема осталась, сообщи фактический формат; не обрезай подписи и не растягивай изображение. Детерминированное добавление полей или конвертация формата разрешены, когда не изменяют содержимое и соответствуют правилам `$imagegen`; содержательные правки выполняй генератором.

## Проверка и выдача

Просмотри результат: смысл, точность текста, отсутствие ложных связей, читаемость, стиль, края и формат. При значимом дефекте сделай целевую правку встроенным генератором, сохранив остальные элементы. Максимум две корректирующие генерации после первой; дальше честно укажи оставшийся дефект и предложи более простую композицию. Не называй непроверенный текст безошибочным.

Встроенный генератор обычно сохраняет файл под `$CODEX_HOME/generated_images/`; используй путь, реально возвращённый инструментом. Сохрани итоговый PNG в указанное пользователем место, иначе в `output/premium-infographic/` текущего workspace. Не перезаписывай существующие результаты: добавляй версию. Если результат не PNG, выполни реальную локальную конвертацию без изменения содержания; смена расширения не является конвертацией. Проверь сигнатуру PNG и размеры. Если сохранить или проверить невозможно, сообщи это и предоставь доступный оригинал.

Рядом сохрани `<topic>-<style>-<format>-vN.prompt.md` с параметрами, полным финальным промптом и ролями референсов. Финальный промпт должен соответствовать последнему вызову, включая уточнение при правке. При выдаче покажи изображение, ссылки на PNG и промпт, кратко назови выбранные настройки и оставшиеся ограничения. Полный промпт предоставь файлом; если файл недоступен — текстовым блоком.
