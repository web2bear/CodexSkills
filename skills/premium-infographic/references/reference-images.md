# Референсные изображения

Референсы можно приложить к запросу, передать локальным путём или хранить для повторного использования в `assets/references/` внутри навыка. Создавай этот каталог при добавлении первого реального референса; пустые примеры не нужны.

Перед подключением локального изображения просмотри его через `view_image`. Выбирай только релевантные файлы. Если путь не доступен, сообщи об этом; не утверждай, что учёл невидимый референс.

Назначь каждому изображению роль: стиль/палитра, композиция, предметная форма или цель редактирования. По умолчанию это ориентир для новой композиции, а не цель буквального редактирования. Не переноси из него неподтверждённые числа, подписи, чужие логотипы или водяные знаки.

Используй `referenced_image_paths`, если все нужные изображения имеют локальные пути. Иначе используй минимально достаточное `num_last_images_to_include` для изображений в разговоре, если фактическая схема инструмента поддерживает этот механизм. Не передавай оба механизма одновременно. Если ни один не охватывает все изображения, попроси прикрепить недостающие снова.

В промпте перечисли роли по порядку: «Image 1 — palette reference; Image 2 — composition reference». Если явно заданный пресет расходится с референсом, сохраняй пресет и используй только совместимые черты референса. Явная просьба пользователя воспроизвести стиль референса имеет приоритет.
