# Number Inbox Notes

Проставляет номера из каталога курса в **имена файлов** заметок Inbox. Не меняет содержимое заметок.

## Когда применять

- Пользователь просит проставить / пронумеровать заметки в Inbox
- В `_Inbox` появились новые страницы курса без номера в имени
- Явно назван этот скилл

## Пути по умолчанию

| Что | Путь |
|-----|------|
| Inbox | `F:\Obsidian\Главное\_Inbox` |
| Каталог | `F:\Obsidian\Главное\_Inbox\Курс Алгоритмы и структуры данных.md` |

Другой каталог или папку использовать только если пользователь их назвал.

## Обязательно запускать скрипт

Не парсить каталог вручную и не писать свой rename. Выполнить скрипт скилла:

```powershell
powershell -NoProfile -File "$env:USERPROFILE\.cursor\skills\number-inbox-notes\scripts\Number-InboxNotes.ps1" -Inbox "F:\Obsidian\Главное\_Inbox" -CatalogName "Курс Алгоритмы и структуры данных.md"
```

Предпросмотр без переименования:

```powershell
powershell -NoProfile -File "$env:USERPROFILE\.cursor\skills\number-inbox-notes\scripts\Number-InboxNotes.ps1" -Inbox "F:\Obsidian\Главное\_Inbox" -CatalogName "Курс Алгоритмы и структуры данных.md" -DryRun
```

Перенумеровать уже пронумерованные файлы (снять старый префикс `N. ` и взять номер из каталога):

```powershell
powershell -NoProfile -File "$env:USERPROFILE\.cursor\skills\number-inbox-notes\scripts\Number-InboxNotes.ps1" -Inbox "F:\Obsidian\Главное\_Inbox" -CatalogName "Курс Алгоритмы и структуры данных.md" -Force
```

## Правила

- Формат имени: `{номер}. {точное название}.md` — как у `1. Чем проще, тем лучше!.md`
- Номер берётся из заголовка каталога вида `[12\. Сумма на отрезках`
- Сопоставление: имя файла без `.md` == заголовок в каталоге (точное, после Trim)
- Номера в каталоге **начинаются заново в каждом разделе**. Это нормально: ищем по названию, не по глобальному счётчику
- Каталог `Курс Алгоритмы и структуры данных.md` не переименовывать
- Уже пронумерованные (`^\d+\.\s`) пропускать, если нет `-Force`
- Несовпавшие файлы не трогать, перечислить в ответе
- Если целевое имя уже занято — не перезаписывать, сообщить о конфликте
- Для имён с `!` и кириллицей скрипт использует `-LiteralPath`

## Ответ пользователю

Кратко по-русски:

1. Сколько файлов переименовано (список `было -> стало`)
2. Какие уже были с номерами
3. Какие не нашлись в каталоге
4. Дубликаты названий в каталоге, если скрипт их вывел (берётся последнее вхождение)

Не предлагать переименовать каталог и не менять frontmatter.
